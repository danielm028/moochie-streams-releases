# Moochie Streams Android TV releases

Download approved beta APKs for Moochie TEST from the GitHub Releases tab
when a release is available. The beta channel serves
`com.example.moochie_streamer.test`. Android displays an installation
confirmation. Keep the existing app installed to retain its local data.

The stable channel is unavailable pending production approval.

Release assets include an APK and a `SHA256SUMS.txt` file. The app independently
verifies signed update metadata and the APK's identity before opening Android's installer.
